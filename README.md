# 🏢 Cozy Office Quest (Office Life)

ยินดีต้อนรับสู่ **Cozy Office Quest** เกมจำลองชีวิตชาวออฟฟิศในรูปแบบ 3D Voxel สไตล์น่ารักๆ ที่พัฒนาด้วย React และ React Three Fiber! ในเกมนี้คุณจะไม่ได้แค่นั่งทำงานหน้าคอมพิวเตอร์เฉยๆ แต่คุณสามารถเดินสำรวจออฟฟิศ ออกกำลังกาย เล่นมินิเกม และแม้กระทั่งขับเฮลิคอปเตอร์ชมวิวบนดาดฟ้าได้!

## ✨ ฟีเจอร์หลัก (Key Features)

### 🎨 1. ระบบสร้างตัวละคร (Character Creator)
ก่อนเริ่มเกม คุณสามารถปรับแต่งตัวละคร Voxel 3D ของคุณได้อย่างอิสระแบบ 360 องศา
- **เพศ & ทรงผม:** เลือกสไตล์ผมสั้นหรือผมยาว
- **ปรับแต่งสีสัน:** เลือกสีผิว (Skin Tone), สีผม, สีเสื้อ, สีกางเกง และสีรองเท้า
- **ตั้งชื่อตัวละคร:** ใส่ชื่อของคุณเพื่อใช้บันทึกสถิติคะแนนบน Leaderboard

### 🏢 2. ออฟฟิศ 3 ชั้นแบบจัดเต็ม (Multi-Level Environment)
ตัวอาคารมีทั้งหมด 3 ชั้นให้สำรวจ โดยมีระบบลิฟต์ (วาร์ปมุมห้อง) ให้สัญจรไปมาได้:
- **ชั้น 1 (Workspace):** โซนทำงานหลัก มีโต๊ะทำงาน คอมพิวเตอร์ และ NPC เพื่อนร่วมงาน
- **ชั้น 2 (Fitness Zone):** โซนออกกำลังกาย มีเครื่องเล่นอย่าง Bench Press (ยกบาร์เบล) และจักรยานปั่น (Stationary Bike) ที่มีแอนิเมชันขยับสมจริง!
- **ชั้น 3 (Rooftop & Helipad):** ดาดฟ้าสุดชิลล์สำหรับพักผ่อน พร้อมลานจอดเฮลิคอปเตอร์!

### 🚁 3. ระบบโต้ตอบและยานพาหนะ (Interactions & Vehicles)
- **นั่งและออกกำลังกาย:** กดปุ่ม `F` ใกล้ๆ เก้าอี้หรือเครื่องออกกำลังกาย เพื่อทำกิจกรรม (แอนิเมชันซิงค์กับการเล่นกล้ามและปั่นจักรยาน)
- **ขับเฮลิคอปเตอร์:** ขึ้นไปที่ชั้น 3 แล้วกด `F` ใกล้ๆ เฮลิคอปเตอร์ เพื่อเทคออฟบินชมวิวรอบเมือง สามารถบินทะลุกำแพงออกไปดูวิวด้านนอกได้ และเมื่อกด `F` อีกครั้งเพื่อลงจอด ระบบจะดึงคุณกลับมาบนดาดฟ้าอย่างปลอดภัย

### 🏸 4. มินิเกมสุดมันส์ (Mini-Games)
คุยกับ NPC ด้วยปุ่ม `E` เพื่อท้าดวลมินิเกม!
- **แบดมินตัน (Shuttle Smash):** กด `Space` ให้ตรงจังหวะเพื่อตีโต้ AI; ผู้ที่ได้ 7 คะแนนก่อนชนะ
- **ฟุตบอล (Goal Kick):** เลือกเป็นคนเตะหรือผู้รักษาประตู แล้วกดปุ่มซ้าย กลาง หรือขวาเพื่อเลือกทิศ; ผู้ที่ได้ 10 คะแนนก่อนชนะ
- **ปิงปอง (Table Rally):** ขยับเมาส์เพื่อคุมไม้ตี และคลิกค้างเพื่อ smash; ผู้ที่ได้ 10 คะแนนก่อนชนะ

### 🌤️ 5. ระบบสภาพอากาศและบรรยากาศ (Dynamic Atmosphere)
ปรับเปลี่ยนเวลาและสภาพอากาศแบบเรียลไทม์ได้จากแถบเมนู (HUD) ด้านบน
- ตอนเช้า (Morning), ตอนเที่ยง (Noon), พระอาทิตย์ตก (Evening), กลางคืน (Night)
- ฝนตก (Rain), หิมะตก (Snow), อากาศร้อนแดดจ้า (Hot)

## 🎮 วิธีการควบคุม (Controls)

- `W`, `A`, `S`, `D` หรือ `Arrow Keys` - เดิน / บังคับเฮลิคอปเตอร์
- `Spacebar` - กระโดด (ปิดใช้งานขณะขับ ฮ.)
- `F` - นั่ง / เล่นเครื่องออกกำลังกาย / ขับเฮลิคอปเตอร์ / ลงจอด
- `E` - พูดคุยกับ NPC / เริ่มเล่นมินิเกม
- `คลิกเมาส์ซ้าย-ขวา` - หมุนมุมกล้อง (Camera Orbit)

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **React.js** - เฟรมเวิร์กหลักในการจัดการ UI
- **@react-three/fiber** - ตัวเชื่อม React กับ Three.js สำหรับสร้างโลก 3D
- **@react-three/drei** - เครื่องมือเสริมสำหรับ Three.js (อาทิ กล้อง OrbitControls, แสงสว่าง, เงา)
- **Zustand** - สำหรับจัดการ State ของเกมทั้งหมด (คะแนน, สถานะการบิน, ชั้นที่อยู่)
- **CSS / Glassmorphism** - ใช้ตกแต่ง UI ให้ออกมาล้ำสมัย

## 🚀 วิธีการรันโปรเจกต์ (How to run)

1. เปิด Terminal แล้วเข้าไปที่โฟลเดอร์ของเกม:
   ```bash
   cd d:\firday\Game\office-quest
   ```
2. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
3. เริ่มต้นเซิร์ฟเวอร์ (Development Server):
   ```bash
   npm run dev
   ```
4. เปิดเบราว์เซอร์ไปที่ `http://localhost:5173` (หรือพอร์ตที่ Vite กำหนด) เพื่อเข้าสู่เกม!
